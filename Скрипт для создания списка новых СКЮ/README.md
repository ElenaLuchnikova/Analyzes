## Создание файла с новыми СКЮ по заданному шаблону
**Задача:** есть файл клиента (maket) с заданными полями. Нужно дополнить его новинками из портала или тулза и проставить статус (обучен продукт или пока еще находится в обучении).

**Как будем решать:**

* Загрузим 2 файла (portal и tools), в каждом из которых частично содержатся нужные поля для макета. 

* Отфильтруем только активные СКЮ из тулза. 

* Соединим датафреймы tools и maket внешним левым соединением и оставим только те продукты, которые есть в датафрейме tools (это и есть новинки). 

* Дополним получившийся датафрейм с новинками new недостающими колонками: соединим его c датафреймом portal (содержащим недостающие колонки) левым соединением по product_id.

* Добавим поле status, где проставим статусы "Обучен" или "В обучении" (условие: обучен, если подтверждено > 15 фейсов).

* Построим барчарт и сравним количество обученных и необученных СКЮ.

* Выгрузим получившийся файл с новинками в Excel
